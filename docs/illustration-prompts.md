# Illustration prompts — BeWell Community

The site is wired for raster illustrations in the style of CCA's BeWell "Learn & Grow" library
(the cards on the live BeWell site: PTSD, Coping With Grief, Managing Stress, etc.). Generate each
image below, save it under the exact filename into `src/illustrations/`, rebuild, and it replaces
the SVG stand-in for that slot automatically. Slots without a file keep the SVG.

## Style block — prepend to every prompt

> Flat vector editorial illustration with a soft painterly texture and fine grain, in the style of
> modern wellbeing-app content cards. Warm, muted, slightly desaturated palette built from: teal
> #2B7272, deep teal #006C77, mint #D3EFE8, amber #FCBA39, coral #F59069, terracotta #A44F28, blush
> #F7CAC9, lilac #B490E4, cream #FBFAF1. Simplified rounded figures with small dot eyes, gentle
> calm expressions, diverse skin tones, casual clothing in the palette colours. Cosy interiors with
> potted plants, soft windows and simple furniture, or soft outdoor scenes with rounded trees and
> hills. Even, calm lighting, subtle shading, no outlines. No text, no letters, no logos, no
> watermark. Composition centred with generous margins so it survives a portrait crop.

Sizes: tiles at **1600×1200 (4:3)**; banners at **2100×900 (21:9)**. Keep the subject in the
middle third — activity tiles crop to portrait, category tiles to landscape, both from the centre.

Generate one image per line. The filename is the contract; the prompt is yours to tune.

## After generating

```bash
# drop the files in, then
npm run build
```

Images are picked up by filename at build time (`import.meta.glob` in `Illustrations.jsx`), so a
`.jpg` or `.webp` with the same stem also works. Anything not yet supplied keeps its SVG stand-in.
